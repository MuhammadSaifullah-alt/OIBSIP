# Calculator

A simple and responsive calculator built using HTML, CSS, and JavaScript as part of the Oasis Infobyte Web Development Internship.

## Features

- Basic arithmetic operations
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)
- Clear (C) functionality
- Responsive design
- Keyboard support
- Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
